# Continental biomass reference summaries

This directory contains compact reference outputs for the two continental
biomass workflows used in the revision:

- `modified_magnabosco/`: the modified workflow.
- `original_magnabosco/`: the original Magnabosco-style workflow.

The archive retains total-biomass tables, model parameters, errors, R-squared
tables, and depth summaries/matrices needed to inspect the reported results.
Per-grid result tables and serialized `.RData` bootstrap objects are excluded:
they account for approximately 722 MB of reproducible intermediate output and
are regenerated by running the corresponding R workflow.

Run the workflows with:

```bash
uv run python scripts/continental/run_workflow.py --workflow modified_magnabosco
uv run python scripts/continental/run_workflow.py --workflow original_magnabosco
```

Each new run is written to a timestamped directory under `runs/continental/`.
